A recent Cybersecurity I've heard is - Cybercriminals exploited compromised credentials belonging to ConnectWise Cloud Backup, a cloud backup service formerly known as SkyKick, to gain unauthorized access to 173 Microsoft 365 customer and partner tenants. The incident highlights the risks of third-party applications that have extensive permissions to access customer data.
ConnectWise took several emergency measures -disabled seven affected application identities, revoked certificates and invalidated shared credentials used for Cloud Backup connections, suspended the Cloud Backup service while its investigation continued, engaged external incident-response specialists to investigate the breach.The company stated that existing backup archives remained encrypted and isolated, with no evidence that the backup archives themselves had been accessed. However, backup and restoration services were temporarily unavailable.
